# Odoo 18 — Модуль управления библиотекой (my_library)

Учебный модуль для Odoo 18, демонстрирующий ключевые навыки разработки:
ORM, наследование моделей, многоуровневая безопасность, workflow и QWeb-отчёты.

## 🛠 Стек
- **Odoo 18 Community**
- **PostgreSQL 16**
- **Docker / docker-compose**
- **Python 3.x**

## 📦 Возможности модуля
- Модель `library.book` (название, автор, ISBN, дата издания, страницы, статус)
- Form / List представления + меню
- **Безопасность (3 уровня):**
  - Группы доступа (`res.groups`)
  - Права на модель (`ir.model.access.csv`)
  - Правила записи (`ir.rule`) — пользователь видит только свои книги
- **Наследование `hr.employee`** — добавлено поле «Читательский билет»
- **Workflow:** кнопки Взять / Вернуть / Утеряна + statusbar
- Переопределение метода `create()` через `super()`
- **QWeb PDF-отчёт** по списку книг

## 🚀 Запуск через Docker

```bash
docker compose up -d
```

Откройте `http://localhost:8069`, создайте базу, активируйте режим разработчика
и установите модуль **my_library** из меню «Приложения».

## 📂 Структура
my_library/
├── models/        — модели и бизнес-логика
├── views/         — XML-представления и меню
├── security/      — права доступа и правила записи
└── report/        — QWeb-шаблоны отчётов
